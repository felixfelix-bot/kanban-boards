# kanban-boards — public shared board space

Fleet-coordination view for **public** kanban boards only (D-126).
Private/operational boards are never exported here.

- `boards/<slug>/` — board metadata + coordination tasks (25 boards, 1327 tasks)
- `repos.json` — board → public project repo
- `ownership.json` — `task_id → {node, ts, status, repo, branch, run_id}`

Task **bodies are intentionally omitted**; only coordination metadata is
published. Generated by `scripts/fleet/export_public_boards.py`.
